## Secuencia explicada
Requisito → Pantalla → Sitemap → User flow → Componentes → Wireframe

| Paso | Ejemplo: editar el pedido (RF-04) |
|---|---|
| Requisito | El estudiante necesita corregir su pedido antes de enviarlo sin perder lo que ya eligió. |
| Pantalla | Editar pedido (2.1) |
| Sitemap | Menú de hoy → Revisa tu pedido → Editar pedido |
| User flow | Revisar → «Editar pedido» → quitar el sanduche → «Guardar cambios» → revisar ($1,50) → confirmar |
| Componentes | Stepper − 1 +, «Quitar», «Guardar cambios», «Cancelar (sin guardar)», mensaje de cambio |
| Wireframe | `06_wireframes/03_editar_paso1_a_2.png`, `04_editar_paso2_a_3.png` |
